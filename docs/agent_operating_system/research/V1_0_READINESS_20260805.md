## Anti-misread rules

   readiness table cannot grant write or execution permission.
2. **The quoted Phase 7 sentence is inert here.** It becomes effective only
   when the Owner places it verbatim in an active implementation instruction
   for that exact session and whitelist.
3. **Approval and audit are not dispatch.** A valid packet, decision, audit
   event, append, or complete chain cannot start a worker, OpenClaw, Phase 9,
   or follow-up action.
4. **A rehearsal is not a real call.** Fixtures, tmp-path files, mock results,
   golden hashes, and in-memory chains do not close Phase 7 or satisfy the
   Owner-present Phase 9 requirement.
5. **Night-batch evidence is branch-scoped.** Unmerged branch results are
   evidence for review, not a new phase-state decision.

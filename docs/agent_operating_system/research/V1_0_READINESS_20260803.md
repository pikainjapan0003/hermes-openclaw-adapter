## Four adversarial anti-misread statements

1. **Ready is not authorized.** A green contract, golden vector, coverage
   report, or readiness table is evidence only and cannot grant a write or
   execution permission.
2. **The quoted Phase 7 sentence is not an active Owner instruction.** It has
   effect only when Owner places it verbatim in the future implementation
   instruction for that session and exact package.
3. **Approval and audit success are not dispatch.** An approved packet, valid
   audit event, successful append, or complete chain cannot start Worker,
   OpenClaw, Phase 9, or any follow-up.
4. **A rehearsal is not a real call.** tmp-path files, mock results, golden
   hashes, a 12-step in-memory chain, and a test-memory `READY` state do not
   satisfy Phase 7 closeout or Phase 9 Owner-present execution.

# Phase 9 給 Owner 的一頁摘要

狀態：**這只是設計稿，還沒有授權製作或執行。**

日期：2026-08-03

## 那天會發生什麼（三句話）

1. 你先看清楚一份「只問問題、不改東西」的任務說明和模擬證據。
2. 你在場確認後，系統最多只准 OpenClaw 問一次；成功、失敗或逾時都不會自動再試。
3. 系統把過程記進防竄改紀錄，確認沒有多做任何事，然後立刻恢復成全部禁止。

## 幾個必要名詞

- **證據包**：執行前的模擬結果，讓你知道它打算做什麼、預期會得到什麼。
- **審批包**：把動作、目標、風險、逾時與停止方法整理成一張你能看的單子。
- **單次密碼（token）**：只對這一張單、這一個動作、這一次有效的臨時密碼；用過或失敗就作廢。
- **執行閘門（gate）**：像只開一次的門；檢查全部通過才開，開一次後永久關閉。
- **預檢（preflight）**：執行前的總檢查；任何一項不確定就不准開始。
- **稽核鏈（audit chain）**：每筆紀錄都扣住上一筆，事後較容易發現被改動。
- **schema（格式規則）**：機器用來拒絕欄位錯誤的表格規則，不是執行許可。
- **rollback（復原）**：出事時如何回復；本次是不寫東西的查詢，正常情況不需復原。

## 你要做的五個動作

| 動作 | 你要看／說什麼 | 約需時間 |
|---|---|---|
| 1. 先選設計 | 在下方各選一個單次密碼方案與格式方案 | 5–10 分鐘，可在執行日前完成 |
| 2. 看證據 | 確認問題、目標、逾時、預期答案與「不寫任何目標」 | 5–10 分鐘 |
| 3. 確認一次 | 保持在線，核對最後畫面；不對就說「停止」 | 2–5 分鐘 |
| 4. 提供單次密碼 | 依你選的方式，當場完成一次密碼確認並說只准這一發 | 約 2 分鐘 |
| 5. 看結果並簽核 | 確認只跑一次、沒有寫入、紀錄完整、門已關閉 | 5–10 分鐘 |

合計約 15–30 分鐘。你可以在任何一步停止。

## 系統真的會做什麼

- 只對你當場看到的那一個無害問題，嘗試呼叫 OpenClaw 一次。
- 在呼叫前後留下不含原始單次密碼的稽核紀錄。
- 記錄結果、逾時或錯誤，檢查是否有未預期的檔案或其他變化。
- 用同一密碼做「再次使用必須被拒絕」的安全檢查；這個檢查只能用假的執行器，不能再次呼叫 OpenClaw。
- 不論成功或失敗，立刻證明執行閘門已回到全部禁止。

## 系統絕對不會做什麼

- 不經 worker（工作程式）、queue（排隊區）或背景排程。
- 不寫 Google Sheet、不叫 connector（外部服務連接器）、不改業務資料。
- 不因成功而多問一次，也不因失敗、逾時或答案看不懂而重試。
- 不把這次成功當成以後都可以執行的長期許可。
- 不把原始單次密碼寫進檔案、紀錄、錯誤訊息或測試資料。
- 不猜 OpenClaw 指令。實際用法與可能寫入的本機狀態，必須在你在場時先確認；不清楚就停止。

「不寫入」指 OpenClaw 的問題本身不修改任何目標。必要的稽核紀錄是另外受控的安全紀錄。若 OpenClaw 會偷偷更新未同意的快取、工作階段或其他檔案，也必須停止，不能把它當成沒關係。

## 選擇一：單次密碼怎麼來

- **T-A：你自己想一組再輸入。** 最直覺，但人想的密碼可能太好猜或重複使用。
- **T-B：系統隨機產生一次，你看見後親自覆述確認。** 較難猜，又保留你親口授權；**建議選這個**。
- **T-C：系統出一道隨機挑戰，你用另外的驗證方式回答。** 最嚴謹但最複雜，第一次演練可能太重。

## 如果你中途想喊停

你只要說「停止」，或離線、沒有回覆、表示不確定，系統就必須立刻關門。還沒開始就完全不呼叫；若已經開始，就只走事先看過的停止方式。這組單次密碼立刻作廢，同一次不能說「繼續」來重開；未來若還想再試，必須重新做證據、審批與全新密碼。

## 你現在的決定不代表什麼

你現在選 T／S 方案，只是在選未來要設計哪一種安全機構；不代表准許寫程式、不代表准許產生真密碼，也不代表准許呼叫 OpenClaw。選完後仍要另開一張逐字授權的實作單，實作經獨立審查通過，再約你本人在線做這一次演練。
